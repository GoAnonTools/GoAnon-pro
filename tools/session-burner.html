Session Burner

Start a temporary session, see what the browser stores, then burn it all — cookies, local storage, session storage, and indexedDB. Nothing survives.

This tool burns real data. It will permanently delete cookies, localStorage, sessionStorage, and indexedDB for this origin. Burning localStorage will also delete data from other GoAnon tools on this domain, including Vaultana vaults, GoAnon Notes, and tool preferences. Export important data before burning. For full isolation, Session Burner should be hosted on its own subdomain (e.g. burn.goanon.pro) so it only burns storage for that subdomain.

  1. 1 Click Start Session to begin. Session Burner records a baseline snapshot of all browser storage on this origin — cookies, localStorage, sessionStorage, and indexedDB databases.
  2. 2 While the session is active, browse or use other tools. Come back to check the inventory — it refreshes each time you view the page and shows new items that appeared since the session started.
  3. 3 When you're done, hit Burn Session. Session Burner deletes all cookies for this origin, clears localStorage and sessionStorage, and wipes all indexedDB databases — including its own session data.
  4. 4 After the burn, the page resets to a clean state. No session data, no cookies, no traces. The session log is also destroyed.

What about cache and history? Browsers do not allow web pages to clear the HTTP cache or browsing history. For full session isolation including cache and history, use the GoAnon Browser (coming soon). Session Burner handles everything a web page can handle.

Full isolation needs a browser. Session Burner works within web page boundaries. For true disposable sessions — with cache clearing, history isolation, container tabs, and network-level separation — look for Session Burner as a feature in the GoAnon Browser.
