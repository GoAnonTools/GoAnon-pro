The honest status

GoAnon Browser is a long-term Labs project. The goal is not to rush another browser skin, but to explore a genuinely independent privacy browser built around GoAnon's principles.

And yes:
It will be ready when it is ready.

Why build a browser?

Privacy decisions need to happen before data leaves the device. A browser built around GoAnon's principles — compartments, disposable sessions, local-first tools, no telemetry — would make strong privacy the default, not a configuration project.

What we want to explore

Not a fork. Not a skin. A browser designed from the ground up to protect users, not monetize them.

  • Compartment-based isolation — banking, shopping, AI tools, work, and disposable sessions separated by default
  • GoAnon tools built in: Shieldana link cleaning, Vaultana, Session Burner, Privana status, Etherana sidebar
  • Tracker and fingerprint protection without breaking the web
  • Local-first features — no account, no sync, no cloud dependency for core functionality
  • No telemetry, no usage reporting, no engagement metrics
  • Disposable session modes for one-off browsing, research, and low-trust workflows

Design principles

  • Privacy by default — not a toggle, not a setting you need to discover
  • No surveillance economy — no hidden data collection, no fingerprinting, no tracking
  • Local-first — your data stays on your device. Cloud features are opt-in, not assumed
  • Transparent — open about what the browser does and does not do. No fake promises
  • Not rushed — built properly, released when it is ready, not when a market window demands it
