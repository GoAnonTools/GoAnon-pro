Privacy model

Etherana SX is designed to keep the workspace local-first and user-controlled. You decide which AI providers or API keys you connect.

  • Default AI direction: Gemma 4.
  • Bring your own API keys when you want external model providers.
  • Local SQLite storage for desktop workspace data.
  • Bundled local SearXNG runtime for desktop search infrastructure.
  • No GoAnon account required for core local desktop use.
  • Encrypted .goanon export/import for backup and portability.

Install notes

These builds are usable, but signing and notarization are future release-maturity steps.

Windows SmartScreen

The Windows installer is not code-signed yet. SmartScreen may show a warning before installation.

macOS Gatekeeper

The macOS build is not notarized yet. Gatekeeper may warn or block the first launch.

Linux AppImage

Make the AppImage executable before launching it.

chmod +x Etherana-SX-linux-x64.AppImage ./Etherana-SX-linux-x64.AppImage
