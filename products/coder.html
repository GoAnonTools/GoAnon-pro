Privacy model

Etherana Coder is designed around user control, manual setup, and privacy-first defaults.

  • No hidden telemetry economy.
  • No GoAnon account required for the public Linux archive.
  • Manual-download-only release metadata; automatic updates are off.
  • Bring your own API keys when you want external model providers.
  • Use local models when you want the most private model path.
  • Partner links and external providers are user-initiated, not automatic background calls.

Install notes
